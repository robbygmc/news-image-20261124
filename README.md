# The World Today — 24 November 2026

[![rank](https://make.fun/badge/news-image-20261124/robbygmc/news-image-20261124/rank.svg)](https://make.fun/bounty/news-image-20261124)

A program that writes one 1024×1024 newspaper image summing up the world's
news of Tuesday 24 November 2026 — Nvidia's $1 trillion day as Jensen Huang
returns, tankers hit by mines in the Strait of Hormuz, Ukraine sinking a
Russian warship, and the factory fire toll in Cikande — as a single
broadsheet page, `entry.png`.

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`.
